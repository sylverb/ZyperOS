ZyperOS 1.0.5 supports 45 systems and a separate Ports shelf. This reference lists every game folder, accepted file type and emulator. Use it when you add games or a game does not appear.

These steps cover ZyperOS 1.0.5. Check your version in MENU > About.

Use the right folder

  1. Open the ZYPEROS drive on your card, or open ZyperOS's File Transfer page.
  2. Find your system in the table below.
  3. Copy the game into that system's folder under Roms/.
  4. Check that its file type matches the table.
  5. Add any required files from the BIOS guide.

The adding games guide explains card readers, USB and Wi-Fi transfers. An empty system stays hidden on the home screen.

The Nintendo 64 shelf offers two included cores. Dreamcast uses flycast2021 by default; standalone Flycast requires a separate installation. A listed system does not promise full speed for every game.

Keep discs and their tracks together

A .cue or .gdi file describes a disc and its tracks. Copy its track files too, in the same relative locations. A PlayStation .bin by itself does not appear as a separate game.

For a multi-disc PlayStation game, make one folder for the game. Put its discs and an .m3u playlist inside. List one disc file per line, with names that match the files:

Disc 1.chd
Disc 2.chd

The shelf treats that folder as one game. For ordinary collections, you can also create folders within a system, such as Roms/Game Boy Advance/Translations/.

Arcade sets and special formats

  • Arcade and Neo Geo: use FinalBurn Neo sets. Keep each archive whole and keep its original name. Neo Geo also needs neogeo.zip in Bios/ or beside the game.
  • MAME: use sets for MAME 2003-Plus. These differ from the FinalBurn Neo sets used by Arcade.
  • ScummVM: copy one folder per game into Roms/ScummVM. An optional .scummvm file inside it contains the ScummVM game ID when automatic detection is unclear.
  • OpenBOR: copy a packed .pak module. An unpacked game folder needs packing first.
  • PICO-8: use .p8 files or .p8.png cart images. Ordinary pictures are not carts.
  • TIC-80: use .tic files or PNG cart images. Its saved game data works, but its core has no save states.
  • PSP: use one of the four file types in the table. PPSSPP needs no separate BIOS. Its game saves use Saves/PSP/SAVEDATA.
  • Ports: the .sh launcher goes directly in Roms/Ports, with the port's data folder beside it. Follow the PortMaster guide for installation.

Doom games and mods

An IWAD contains a complete game. Put it in Roms/Doom. A PWAD contains a mod and needs its base IWAD beside it.

To choose a specific IWAD or load several mods, create an .m3u file. Put the IWAD first, then one mod per line:

doom2.wad
my-mod.wad

Without a playlist, PrBoom uses an IWAD from the same folder and prefers Doom II. Save states work inside a level.

Use folders from another system

ZyperOS also accepts EmulationStation folder names, such as gba, nds, psx and megadrive. Copy those system folders into Roms/.

Each system reads one folder. ZyperOS uses its normal folder when that folder contains a game. Otherwise, it uses the accepted alternate folder with the most games. It does not combine both folders into one shelf.

Put games for one system together if you want them on one shelf. The missing games checks cover rescanning and file types.

Folder names and file types follow the ZyperOS 1.0.5 system configuration. Emulator names and special format notes follow its user documentation.
