ZyperOS uses the same menu buttons across the library. Game controls depend on the system. The handheld has a controls page for both, plus six save-state slots where the emulator supports them.

These steps cover ZyperOS 1.0.5. Check your version in MENU > About.

Everyday buttons

ButtonAction
A / BOpen or select / go back
X on a gameOpen its details; Y there changes its favorite status
START on a game shelfSwitch covers and list
L1 / R1Jump along a shelf; change tabs in the home menu
MENUOpen settings or pause into the game menu
MENU + VOL+ / VOL-Increase or decrease screen brightness
SELECT outside a running gameOpen MP4 for music, books and videos

On the Pixel 2, MENU is the FUNCTION key. It opens the menu when you release it. MENU > About > Controls lists all common buttons.

Find a system's controls

During a game, open MENU > Controls. Left and Right turn pages. The first pages show the system's buttons. Later pages show hotkeys and common actions.

For example, PSP uses R2 to switch the D-pad between digital and analog control. Nintendo DS uses L2 to swap screens. Its R2 enables the stylus controls. The Nintendo DS guide explains the layouts and stylus.

Game saves and save states

A game save records progress through the game's own save system. A save state records the emulator at a specific moment. Use the game's save command when available.

  1. Open MENU > Save during play.
  2. Select one of the six numbered slots with Left or Right.
  3. Press A to save the state.
  4. Use MENU > Load to select and restore it later.

Saving to an occupied slot replaces its state. ScummVM, J2ME, OpenBOR and TIC-80 do not provide these save states. Use their own save systems.

A state belongs to its emulator. Changing a core can prevent resume, while the game's save remains.

Quick saves and speed

SELECT + R1 saves; SELECT + L1 loads. Quick Slot in the game menu selects their numbered slot. Each system remembers its choice.

SELECT + R2 increases speed through 1.5x, 2x and 3x. SELECT + L2 reduces it. The actual speed depends on the game, and fast play has no sound.

Stop and resume

For games with state support, POWER saves before shutdown. The next start resumes that game. On the shelf, A resumes an available state; Y starts fresh.

To return to the shelf, press MENU, then X. If a game stops responding, hold MENU + START for one second. After a crash or power loss, ZyperOS opens the home screen.

Back up game saves and save states before changing emulators or removing games. The File Transfer guide explains file downloads.
