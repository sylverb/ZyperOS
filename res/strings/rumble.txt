# Rumble's levels (src/rumble.c): MENU > Sound > Rumble for every game, and
# the in-game Controls tab's Rumble row for a game or its system. Off is
# menu.off_title. Each value begins with a capital, as a row's value does
# (GLOSSARY.md); the words are the ones a console's own vibration setting
# uses in each language.
